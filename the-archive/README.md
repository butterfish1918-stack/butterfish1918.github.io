# The Archive · Antwerp Edition

Mobile/PWA build of **The Archive** for GitHub Pages and Android.

## Live app

`https://butterfish1918-stack.github.io/the-archive/`

## Android

Open the live URL in Chrome and use **Install app** / **Add to Home screen**. The app runs in standalone mode and caches its shell for repeat/offline use.

## Storage

The app works immediately using private on-device browser storage. Imported outfits, perfumes, archetypes and hairstyles persist on that device.

For cross-device cloud sync, add a Firebase Web App configuration to `config.js`, enable Anonymous Authentication, and configure Firestore security rules.
