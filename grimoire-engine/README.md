# The Grimoire Engine

Mobile-ready GitHub Pages build of the supplied React guitar-theory and practice application.

## Features preserved

- Full scale/mode library and interval architecture
- 24-fret interactive fretboard and sigil visualisation
- Harmonised chords, generated playable tablature and stave notation
- WebAudio note/chord playback
- Explore, Practise, Quiz and Live modes
- Live BPM/metronome stream, random notes, scale runs, chord strums and arpeggios
- Selectable fret/string practice zones
- Mobile horizontal swipe for dense matrix/fretboard views instead of removing or compressing features
- PWA manifest and service worker for installable mobile use

Open the deployed app at the `/grimoire-engine/` path of this GitHub Pages site.
