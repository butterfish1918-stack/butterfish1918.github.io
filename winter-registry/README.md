# The Winter Registry — Prototype 0.1

Playable browser/PWA vertical slice for a survival-administration game.

## Current prototype
- Isometric click/touch field map
- Time-costed scavenging and site depletion
- 30 persistent residents
- Imperfect information and field assessments
- Cohort and individual ration allocation
- Nutrition, heat, medicine and scrap resources
- Dissent, health, hunger, warmth and radiation simulation
- Procedural mutations with mechanical trade-offs
- Night resolution and generated consequences
- Fourteen-day prototype term and collapse ending
- Final obituary CSV export
- Seeded village state
- Local save/continue
- Offline service worker and installable web-app manifest
- Responsive Android-friendly interface
- Procedural WebAudio ambience

The prototype is deliberately dependency-free so GitHub Pages can serve it directly.
