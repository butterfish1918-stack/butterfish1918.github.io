# Hyper-Liminoid v11.2 — Transparent Vortex

Mobile/PWA build of the Hyper-Liminoid interactive spatial synthesizer for GitHub Pages and Android.

## Live app

https://butterfish1918-stack.github.io/butterfish1918.github.io/hyper-liminoid/

## Android

Open the live app in Chrome on Android, tap **Reveal the Core** to enable Web Audio, then use **Install App** when Chrome offers installation. You can also use Chrome's menu and choose **Add to Home screen / Install app**.

The mobile build preserves the original temperament systems, per-note controls, waveguide feedback, shadow bass and visual engine while adding responsive layouts, pointer/touch handling, safe-area support, audio resume handling and offline PWA caching.
